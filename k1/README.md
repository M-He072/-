# 设计作品集模板（可编辑单文件）

一个面向 **视觉 / 平面 / 品牌设计师** 的响应式作品集网页模板。单文件 HTML，无需构建工具，可直接在浏览器里编辑文字、图片与链接，一键导出成品。

## ✨ 特性
- 编辑式留白排版，思源宋体（标题）+ 思源黑体（正文）的高级感组合
- 右下角「＋」入口：**网页内直接改文字 / 加图片 / 新增作品卡 / 保存网页**
- 作品分类筛选、滚动淡入动效、移动端自适应
- 改配色只动 `:root` 里的 `--accent / --paper / --ink` 三个变量

## 🚀 使用方法
1. 双击 `index.html` 用浏览器打开。
2. 点右下角 **＋ → 编辑内容（文字＋图片）** 开始改：
   - 改文字：直接点文字编辑
   - 改图片：点占位区选本地图
   - 改链接：双击导航名 / 邮箱 / 社交链接
3. 改完点 **保存网页（含改动）** 下载成品。
4. 导出 PDF：浏览器「打印 → 另存为 PDF」。

## 📦 部署到 GitHub Pages
1. 在 GitHub 新建仓库，把本目录文件（`index.html`、`README.md`）上传。
2. 仓库 **Settings → Pages → Source** 选 `main` 分支根目录 → Save。
3. 等待约 1 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。

> 也可直接把 `index.html` 拖到 GitHub 仓库根目录，提交后即可开启 Pages。

## 📐 图片建议
- 作品图 4:3，约 1200×900px；个人照 4:5，约 1000×1250px；案例大图 1:1，约 1200×1200px
- 单张压到 ~200KB；若用「保存网页」导出单文件，整页图片总量建议 ≤ 2MB

## 📝 说明
- 字体走 Google Fonts CDN，离线时自动回退系统字体，排版不崩。
- 定稿后可删除 `index.html` 里 `editor-launch` 那一段（网页内编辑入口）及其对应 CSS/JS。
- 本模板为通用示例，不含任何个人隐私信息，可自由分享与二次修改。
