# 设计作品集模板 · 介绍

> 一份面向视觉 / 平面 / 品牌设计师的**可编辑单文件作品集模板**。
> 不依赖任何构建工具，浏览器打开即可改文字、加图片、导出成品——把做作品集的时间，还给做设计本身。

---

## 为什么做这个模板

设计师找工作时，最大的内耗往往不是"没作品"，而是"作品集太难做"：

- 用设计软件排一版，改个字要重导出；
- 用通用建站工具，样式被框死，高级感出不来；
- 投不同岗位要换内容，复制来复制去容易乱。

这个模板的思路很简单：**把"展示"和"编辑"分开**——默认是一份有质感的成品页面，需要改时，点一下就能在网页里直接改，改完导出一份干净的新页面。

---

## 核心亮点

- **真·网页内编辑**：右下角「＋」入口，文字直接点改、图片点占位区即选、链接双击改地址，全程不碰代码。
- **一键导出成品**：「保存网页」把当前页（含已内嵌图片）序列化下载，刷新不丢、可直接投递。
- **高级感排版**：思源宋体标题 + 思源黑体正文，暖白纸张底 + 赭红强调色，大留白 + 滚动淡入，中文排版里最稳的质感组合。
- **零依赖单文件**：一个 `index.html` 走天下，双击即开，方便分享链接，也方便转 PDF 或部署上线。
- **模板感强、留白足**：封面 / 关于 / 精选作品（带筛选）/ 重点案例 / 能力 / 经历 / 联系，结构按面试阅读顺序排布。
- **改动成本低**：换配色只动 `:root` 里的三个变量；加作品卡有现成结构可复制。

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 文字编辑 | 导航、封面、自我介绍、作品标题、经历、联系方式，点哪改哪 |
| 图片替换 | 个人照 / 作品图 / 案例大图，点占位区选本地图，自动裁切适配 |
| 链接编辑 | 双击邮箱 / 社交链接改地址；改邮箱文字自动同步 `mailto:` |
| 新增作品 | 一键追加带占位图的新卡片，自动带动画与筛选分类 |
| 分类筛选 | 作品区顶部可按「品牌 / 海报 / 视觉」筛选 |
| 导出网页 | 导出含图片与改动的干净 `index.html` |
| 导出 PDF | 浏览器「打印 → 另存为 PDF」即可 |

---

## 快速开始

1. 双击 `index.html` 用浏览器打开。
2. 点右下角 **＋ → 编辑内容（文字＋图片）**，开始改你的信息。
3. 改完点 **保存网页（含改动）**，下载成品。
4. 想上线：传到 GitHub 开 Pages，或部署到任意静态托管。

## 设计语言

- **字体**：标题用思源宋体（Noto Serif SC），正文用思源黑体（Noto Sans SC），走 Google Fonts CDN，离线自动回退系统字体。
- **配色**：暖白纸张底 `--paper`、墨黑文字 `--ink`、赭红强调 `--accent`，均在 `:root` 定义，一行即可换品牌色。
- **节奏**：大留白、细分隔线、序号编排，靠"空"出质感，而不是靠装饰堆砌。
- **动效**：滚动进入视口淡入，克制不喧宾夺主。

## 技术说明

- 纯静态单文件 HTML + 内联 CSS/JS，无框架、无打包。
- 图片编辑以 data URL 内嵌，单文件即可携带全部内容；正式部署建议改外链图片以减小体积。
- 响应式布局，移动端自适应；`object-fit: cover` 按容器比例裁切，源图接近显示比例时不易切掉重点。

## 图片规格建议

- 作品图 4:3，约 1200×900px；个人照 4:5，约 1000×1250px；案例大图 1:1，约 1200×1200px。
- 单张压到 ~200KB；若用「保存网页」导出单文件，整页图片总量建议 ≤ 2MB。

## 自定义

- 改配色：编辑 `:root` 里的 `--accent / --paper / --ink`。
- 加作品：复制一整段 `<article class="work">`。
- 定稿后可删除 `index.html` 里 `editor-launch` 那一段（网页内编辑入口）及其对应 CSS/JS，得到纯展示页。
